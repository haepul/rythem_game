## 확인된 근거와 남은 한계

- 배포 준비 시 fetch 후 로컬HEAD=origin/main. force push 없이 정상 fast-forward push 예정.
- 가챠/메뉴226/226 및 judgment3d 통과. 게임UI59/59는 DAY14 검증 로그에 기록되어 있다.
- 실제 Chromium 격리 앱 흐름, 두탭 잔액갱신, 새로고침/NEW/기록 보존, 5크기 iframe 검증은 DAY14 증거 참조.
- 사용자가 “음악의 어긋남은 없고 판정도 괜찮은 것 같다”고 직접 답했다. 이는 사용자 청음 피드백이며 자동 싱크 측정이나 특정 모바일 기기 검증은 아니다.
- 실제 브라우저200%, 물리적 탭숨김/OS모션 설정, Android/iOS 실기기, Safari/Firefox/스크린리더, 장기 성능은 미검증. native Chrome의 URL식별 안전검사로 자동 조작이 차단되었으며 우회하지 않았다.
- 사용자의 최신 배포 요청에 따라 미검증 목록을 공개 상태의 제한으로 남긴다. 모든 검사 통과나 상용 품질 인증을 의미하지 않는다.

## 저장 전환

같은 가챠키의 v1/v2 잔액/지급기록/receipt를 보존해 schema3로 전환한다. 읽기에서 메모리상 마이그레이션, 다음 성공한 잠금 쓰기에서 저장한다. 다른 게임키는 건드리지 않는다. 구버전 탭은 새schema를 읽지 못하면 안전하게 쓰기를 거부한다. 오래된 탭은 새로고침해야 한다. 손상/미래버전은 자동 초기화하지 않는다.

## 배포 후 증거

이 커밋을 만든 뒤에만 배포 SHA·Actions 결과·공개 파일 해시를 확인할 수 있다. 따라서 사전 문서에서 성공을 단정하지 않는다. 완료 응답에는 실제 commit SHA, Actions 링크, 공개 주소와 검사 결과를 제공한다. 운영 저장은 초기화하지 않고 전용 fixture 저장으로 공개 시험한다.
